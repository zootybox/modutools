modutools 소개 — 모두를 위한 무료 온라인 도구

개발자 박성재가 만든 100% 브라우저 로컬 처리 웹 도구 모음

modutools.com은 "모두를 위한 도구"라는 뜻을 담고 있습니다. 연봉 실수령액 계산기, 이미지 압축, OCR 텍스트 추출, PDF 합치기, 글자수 세기, 단위 변환 등 일상과 업무에서 필요한 40여 개의 온라인 도구를 누구나 무료로, 설치 없이, 회원가입 없이 사용할 수 있도록 만들었습니다.

이 사이트의 가장 큰 특징은 모든 처리가 사용자의 브라우저(클라이언트)에서만 이루어진다는 점입니다. 입력한 데이터가 외부 서버로 전송되지 않으므로, 개인정보, 금융 정보, 민감한 문서도 안심하고 사용할 수 있습니다. 이는 Google의 Tesseract.js, pdf-lib, Canvas API 등 최신 웹 표준 기술을 활용하여 구현되었습니다.

기술 스택과 보안

modutools는 순수 HTML, CSS, JavaScript(Vanilla JS)로 구축되었으며, 별도의 백엔드 서버나 데이터베이스가 없습니다. 주요 기술 스택은 다음과 같습니다:

  • 이미지 처리 — Canvas API, File API, Tesseract.js (OCR)
  • PDF 처리 — pdf-lib (CDN), jsPDF
  • QR 코드 생성 — qrcode-generator (CDN, 로컬 인코딩)
  • 음성 합성 — Web Speech API (브라우저 내장 TTS)
  • 데이터 저장 — localStorage (최근 사용 도구 기록, 서버 전송 없음)

모든 CDN 라이브러리는 브라우저에서 실행되는 클라이언트 사이드 라이브러리이며, 어떤 데이터도 외부 서버로 전송되지 않습니다. 사용자가 업로드한 파일은 브라우저 메모리에서만 처리되고, 탭을 닫으면 자동으로 삭제됩니다.
