📖 랜덤 숫자 생성 가이드

랜덤 숫자 생성기는 사용자가 지정한 범위 내에서 무작위 숫자를 생성합니다. 중복 허용/제외 옵션을 선택할 수 있으며, 여러 개의 숫자를 한 번에 생성할 수 있습니다.

로또 번호 생성(1~45, 6개, 중복 제외), 제비뽑기, 순서 정하기, 난수표 생성 등 다양한 용도로 활용 가능합니다. Math.random() 기반의 균등 분포 난수를 사용합니다.

용도범위 설정개수
로또 번호1~456개
제비뽑기1~인원수1개
난수표0~9999여러 개
로또 번호 생성 시 중복 제외는 어떻게 동작하나요?
1~45 범위에서 중복 없이 6개 숫자를 무작위 추출합니다. 각 숫자는 동일 확률로 선택됩니다.
진정한 난수와 의사 난수의 차이는 무엇인가요?
Math.random()은 의사 난수로, 알고리즘 기반이지만 실용적인 목적에는 충분한 무작위성을 제공합니다.
생성 결과가 편향될 수 있나요?
Math.random()은 균등 분포를 보장하므로, 충분한 샘플에서는 각 숫자가 비슷한 빈도로 나타납니다.
입력한 정보가 서버에 저장되나요?
아닙니다. 모든 처리는 브라우저에서만 이루어집니다.
