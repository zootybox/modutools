📖 서버 전송 없는 무료 OCR 텍스트 추출 방법

modutools의 OCR 도구는 구글의 Tesseract.js 엔진을 사용하여 100% 브라우저에서 동작합니다. 업로드한 이미지가 외부 서버로 전송되지 않으므로, 신분증, 계약서, 영수증 등 민감한 문서도 안전하게 처리할 수 있습니다. 인식된 텍스트는 브라우저 메모리에서만 처리되며, 작업 완료 후 자동 삭제됩니다.

  • 지원 형식: JPG, PNG, WebP (최대 20MB)
  • 지원 언어: 한국어, 영어 (동시 인식 가능)
  • 활용 예: 스캔 문서 디지털화, 명함 인식, 영수증 데이터 추출, 외국어 간판 번역, PDF 내 이미지 텍스트 추출
  • 처리 속도: 이미지 크기와 언어 데이터 로딩 시간에 따라 3~15초 소요됩니다. 첫 실행 시 언어 데이터를 다운로드하므로 추가 시간이 필요할 수 있습니다.
🔍 인식률을 높이려면 어떻게 해야 하나요?
이미지가 선명하고 글자와 배경의 대비가 뚜렷할수록 인식률이 높아집니다. 기울어진 문서는 미리 회전 보정하고, 어두운 이미지는 밝기를 조정한 후 업로드하세요. 인쇄된 활자체는 90% 이상의 높은 인식률을 보이지만, 손글씨나 특수 폰트는 인식률이 낮을 수 있습니다. 해상도는 300DPI 이상이 권장됩니다.
🌐 인터넷 연결이 필요한가요?
네, 첫 번째 OCR 실행 시 Tesseract.js 언어 데이터(약 2~5MB)를 다운로드하기 위해 인터넷 연결이 필요합니다. 이후 동일 언어로 다시 사용할 때는 브라우저 캐시를 활용하여 추가 다운로드 없이 오프라인으로도 사용 가능합니다.
📄 PDF 파일에서 OCR을 할 수 있나요?
현재는 이미지 파일(JPG, PNG, WebP)만 지원합니다. PDF 파일의 경우 먼저 이미지로 변환한 후 OCR 도구를 사용해주세요. (PDF 페이지를 캡처하거나, modutools의 이미지 변환 도구를 활용할 수 있습니다.)
🔒 개인정보 보호는 어떻게 이루어지나요?
모든 OCR 처리는 사용자의 브라우저 내에서만 이루어집니다. Tesseract.js 엔진이 로컬에서 이미지를 분석하며, 어떤 데이터도 외부 서버로 전송되지 않습니다. 업로드한 이미지와 추출된 텍스트는 서버에 저장되지 않으며, 브라우저 탭을 닫으면 자동으로 삭제됩니다. 작업 완료 후 페이지를 새로고침하거나 '새로 하기' 버튼을 클릭하면 메모리에서도 안전하게 제거됩니다.
