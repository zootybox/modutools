만 나이 통일법 시행

2023년 6월 28일부터 법적·행정적으로 만 나이가 통일 기준이 되었습니다. 기존에 한국에서 사용하던 세는 나이(한국 나이)와 연 나이 대신, 생일을 기준으로 계산하는 만 나이가 공식 나이로 사용됩니다. 이에 따라 계약서, 법률, 행정 서류에서는 만 나이만 인정됩니다.

세 가지 나이 체계

만 나이는 태어난 날을 0세로 시작하여 매년 생일에 1살 증가합니다. 세는 나이(한국 나이)는 태어나면서 1살이고 매년 1월 1일에 1살이 추가됩니다. 연 나이는 현재 연도에서 출생 연도를 뺀 값으로, 학교 입학이나 병역 판정 등에서 사용됩니다.

띠(12간지)란?

12간지는 쥐, 소, 호랑이, 토끼, 용, 뱀, 말, 양, 원숭이, 닭, 개, 돼지 순서로 12년 주기로 반복됩니다. 출생 연도를 12로 나눈 나머지로 띠를 확인할 수 있으며, 한국에서는 새해 인사나 궁합을 볼 때 자주 활용됩니다.

❓ 자주 묻는 질문
만 나이와 세는 나이의 차이는?

만 나이는 태어난 날을 0세로 시작해 생일이 지날 때마다 1살 증가합니다. 세는 나이(한국나이)는 태어나면서 1살, 매년 1월 1일에 1살 추가됩니다. 2023년 6월부터 법적으로 만 나이가 기준이 됩니다.

연 나이란 무엇인가요?

연 나이는 현재 연도에서 태어난 연도를 뺀 값입니다. 생일과 관계없이 같은 해에 태어난 사람은 모두 같은 연 나이를 가집니다. 학교 입학, 병역 등에서 사용됩니다.

띠는 어떻게 정해지나요?

12간지(쥐·소·호랑이·토끼·용·뱀·말·양·원숭이·닭·개·돼지) 순서로 태어난 해에 따라 정해집니다. 12년 주기로 반복됩니다.

클라이언트 브라우저 로컬 처리 안내

본 도구는 100% 클라이언트 사이드(브라우저)에서만 동작합니다. 입력한 데이터는 외부 서버로 전혀 전송되지 않으며, 사용자의 브라우저 메모리에서만 일시적으로 처리됩니다. 모든 JavaScript 코드와 CSS 스타일은 브라우저 내에서 로컬 실행되므로, 개인정보, 금융 정보, 문서 등 민감한 데이터도 안심하고 사용할 수 있습니다.

파일 업로드 시에도 Canvas API, Web Audio API, FileReader API 등 브라우저 내장 API를 통해 로컬에서 직접 처리되며, 어떤 파일도 서버에 저장되거나 외부로 전송되지 않습니다. 작업 완료 후 브라우저 탭을 닫으면 모든 데이터는 자동으로 삭제됩니다.

이 도구는 어떻게 작동하나요?
모든 처리는 사용자의 브라우저에서만 이루어집니다. 서버로 데이터를 전송하지 않기 때문에 업로드 속도가 빠르고, 개인정보가 외부로 유출될 위험이 없습니다. 회원가입이나 로그인도 필요하지 않습니다.
입력한 데이터는 안전한가요?
네, 입력한 모든 데이터는 사용자의 브라우저 메모리에서만 처리됩니다. 서버로 전송되거나 저장되지 않으며, 브라우저 탭을 닫으면 완전히 삭제됩니다. 금융 정보, 개인 문서, 민감한 파일도 안심하고 사용할 수 있습니다.

서버 기반 도구가 아니므로 횟수나 용량에 제한이 없습니다. 사용자의 브라우저 메모리가 허용하는 범위 내에서 무제한으로 사용할 수 있습니다. 회원가입이나 결제가 필요하지 않은 완전 무료 도구입니다.

네, 모든 도구는 반응형으로 설계되어 스마트폰, 태블릿, PC 등 모든 기기에서 사용할 수 있습니다. 모바일 브라우저에서도 동일한 기능을 제약 없이 사용할 수 있습니다.
