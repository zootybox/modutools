무료 TTS 텍스트 음성 변환

텍스트를 자연스러운 음성으로 변환. 한국어·영어 지원, 속도·톤·볼륨 조절 가능. · 100% 브라우저 로컬 처리

🔒 서버 전송 없음 · 100% 브라우저 로컬 변환

📖 TTS 음성 변환 가이드

TTS는 Web Speech API를 사용하여 브라우저에서 직접 텍스트를 음성으로 변환합니다. 서버 전송 없이 로컬에서 처리되므로 개인정보가 안전합니다.

한국어와 영어를 지원하며, 성별, 속도, 톤, 볼륨을 세부 조절할 수 있습니다. 생성된 음성은 WAV 파일로 다운로드하여 저장할 수 있습니다.

언어지원 음성품질
한국어여성/남성자연스러움
영어(미국)여성/남성매우 자연스러움
Web Speech API는 인터넷이 없어도 작동하나요?
네, 음성 데이터가 캐시되면 오프라인에서도 사용 가능합니다.
음성 파일을 다운로드할 수 있나요?
네, WAV 형식으로 음성 파일을 다운로드하여 저장할 수 있습니다.
최대 몇 글자까지 변환 가능한가요?
브라우저에 따라 다르지만 일반적으로 수천 자까지 지원합니다.
입력한 텍스트가 서버에 저장되나요?
아닙니다. Web Speech API는 브라우저 내장 API로 서버 전송이 없습니다.
