암호화된 PDF도 병합할 수 있나요?
암호가 설정된 PDF는 병합할 수 없습니다. 먼저 암호를 해제하세요.

아닙니다. 모든 처리는 브라우저에서만 이루어집니다.

📖 PDF 병합 가이드

PDF 합치기는 pdf-lib 라이브러리로 브라우저에서 직접 여러 PDF 파일을 하나로 병합합니다. 최대 100개 파일까지 업로드 가능하며, 드래그로 순서를 변경할 수 있습니다.

공공기관 제출용으로 여러 문서를 하나의 PDF로 합칠 때 유용합니다. 이메일 첨부 시 대부분 25MB 이하가 요구되므로 병합 후 용량을 확인하세요.

기능설명
파일 업로드드래그 앤 드롭 또는 클릭
순서 변경드래그로 자유롭게 조정
최대 파일100개까지 동시 병합
PDF 병합 시 파일 크기가 너무 커지면 어떻게 하나요?
병합 전 각 PDF의 이미지를 압축하면 최종 파일 크기를 줄일 수 있습니다.
