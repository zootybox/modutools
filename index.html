📝 텍스트 도구 — 글자수 세기(공백 포함/제외, 바이트, 단어, 문장 수), 대소문자 변환(UPPER/lower/Title/Sentence/camelCase), 공백 정리(연속 공백·줄바꿈·탭 정리), 중복 줄 제거(순서 유지 옵션), OCR 이미지 텍스트 추출(한국어+영어)을 제공합니다.

🔄 변환기 — 이미지를 PDF로 변환(여러 장 합치기, 순서 변경, 용지 설정), PDF 병합, 단위 변환(길이·무게·면적·부피·온도·속도·데이터), 날짜 계산(D-Day·날짜 차이·날짜 더하기), 시간대 변환, 나이 계산(만나이·한국나이·띠), 색상 코드 변환(HEX·RGB·HSL), TTS 텍스트 음성 변환을 지원합니다.

🏠 생활 도구 — BMI 계산(대한비만학회 기준·정상 체중 범위·이상 체중), 전기요금 계산(주택용 누진세), 연차 계산(근로기준법 기준), 학점 계산(4.5/4.3만점)을 지원합니다.
